# Planner — планировщик задач для Android

## Идея
Простое приложение-планировщик: пользователь записывает задачи, при желании указывает срок
(дату и время) и получает push-уведомление в момент срока. Все данные хранятся **только локально**
на устройстве, без аккаунтов, сервера и сети (в манифесте нет разрешения INTERNET).

## Границы MVP
Входит:
- создание, редактирование, удаление задачи (название, заметка, срок);
- отметка «выполнено»; фильтры «Активные / Выполненные / Все»;
- локальное хранение (Room / SQLite);
- уведомление в момент срока; уведомления переживают перезагрузку устройства;
- запрос разрешения на уведомления (Android 13+).

Не входит (на будущее): повторяющиеся задачи, категории/теги, поиск, виджет, синхронизация,
резервные копии, подзадачи, настраиваемые напоминания «за N минут».

## Стек и обоснование
| Область | Выбор | Почему |
|---|---|---|
| Язык | Kotlin 2.0 | стандарт Android |
| UI | Jetpack Compose + Material 3 | минимум кода и XML, динамические цвета |
| Навигация | navigation-compose | два экрана, достаточно |
| Хранение | Room (+KSP) | типобезопасный SQLite, Flow для реактивного UI |
| Архитектура | MVVM, ViewModel + StateFlow, ручной DI через `AppContainer` | для MVP Hilt избыточен |
| Уведомления | `AlarmManager` (exact при наличии разрешения, иначе inexact) + `BroadcastReceiver` + `NotificationCompat` | работает при закрытом приложении |
| Восстановление | `BOOT_COMPLETED` / `MY_PACKAGE_REPLACED` receiver | alarm'ы сбрасываются при перезагрузке |
| Сборка | Gradle KTS, version catalog, minSdk 26, target/compile 35 | |
| CI | GitHub Actions: сборка debug APK + unit-тесты | |

### Итерация 2: календарь
Главная вкладка — календарь; вторая вкладка — список задач (нижняя навигация).
- Событие = задача со сроком. У события есть **цвет** (палитра из 8 цветов) и необязательная
  **протяжённость** — дата окончания (`endDay`), не раньше дня начала.
- Месячная сетка: однодневные события — **точки** (до 3 в клетке), протяжённые — **скруглённые полосы**
  на всё время события; на стыке недель полоса продолжается без скругления. Перекрывающиеся
  события раскладываются по «дорожкам» (до 3 на неделю, остальные видны в списке дня).
- Нажатие на день показывает его события; «+» создаёт задачу с этим днём.
- Задачи без срока в календаре не показываются, остаются во вкладке «Задачи».
- Напоминание срабатывает в момент начала события (как и раньше).

Задачи итерации: [x] модель и миграция БД (цвет, дата окончания); [x] логика раскладки недели + тесты;

## Известные ограничения MVP
- На Android 13+ точные будильники (`SCHEDULE_EXACT_ALARM`) по умолчанию выключены; без разрешения
  уведомление может прийти с задержкой в несколько минут. Экран выдачи разрешения — задача после MVP.
